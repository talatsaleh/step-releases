# Step — Android

نسخ تطبيق **Step** لأندرويد. المستودع ده فيه ملفات التثبيت بس — الكود مش هنا.

**آخر نسخة دايماً:**
https://github.com/talatsaleh/step-releases/releases/latest/download/step.apk

أو من الموقع: https://www.stepeducationapp.com/update

### التركيب
1. نزّل `step.apk` من الرابط فوق.
2. أندرويد هيسألك تسمح بالتركيب من المصدر ده — اسمح مرة واحدة.
3. افتح الملف من «التنزيلات» واضغط «تركيب». التركيب فوق النسخة الحالية بيحافظ على حسابك وبياناتك.
